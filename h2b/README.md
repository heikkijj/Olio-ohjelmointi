# Olio-ohjelmointi – Kurssin kotitehtävät

Tämä repositorio sisältää olio-ohjelmoinnin kurssin harjoitustehtävät.

*  -Jokainen harjoitus on sijoitettu omaan kansioonsa (esim. `h1`, `h2`).
*  -Kukin kansio sisältää tarvittavat lähdekooditiedostot (C++), jotka ohjelman suorittaminen vaatii.

* --Kieli:-- C++
* --Kehitysympäristö / Työkalut:-- VS Code, GCC / MinGW (UCRT64)
